# sd-space3ds
This is sd-space3ds, a homebrew tool for the 3DS that tells you how much space you have left on your SD card. Available as a .3dsx file.


# Instructions
Press A to cycle between MB, GB, KB, and bytes.

Press START to exit back to the homebrew channel.
